# Учебный набор данных Qaqpan 232

Файл `offers.csv` содержит 256 примеров вакансий и сообщений на русском и казахском языках. Скрипт `scripts/train_model.py` создаёт варианты из базовых фраз, написанных вручную.

Опасные примеры основаны на действиях, которые описаны в официальных материалах Казахстана о дропперстве: передача карты, доступ к банкингу, приём и пересылка денег, снятие наличных, комиссия за перевод и просьба скрыть правду от банка.

Безопасные примеры описывают обычные вакансии с понятными обязанностями, договором и фиксированной оплатой.

## Поля

- `text`: текст сообщения;
- `language`: язык, `ru` или `kk`;
- `label`: `1` для рискованного примера и `0` для безопасного;
- `group`: номер базового шаблона;
- `source_kind`: способ создания примера.

## Как разделены данные

Все варианты одного базового сообщения остаются вместе. Они попадают либо в обучение, либо в тест. Это не даёт модели увидеть почти одинаковый текст с двух сторон и просто запомнить ответ.

## Ограничение

Это небольшой синтетический набор. В нём нет переписок реальных пострадавших. Результаты на нём нельзя выдавать за точность на реальных данных.
