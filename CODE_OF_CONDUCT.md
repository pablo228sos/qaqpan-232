# Code of Conduct

Qaqpan 232 is an open-source project for people working across different languages, experience levels, and backgrounds. Project spaces should stay technical, respectful, and useful.

## Expected behavior

- Discuss code, data, documentation, design, and research on their merits.
- Give specific feedback without personal attacks.
- Assume good faith while still reviewing changes critically.
- Respect privacy. Do not post private conversations, credentials, personal identifiers, or victim data.
- Credit other people's work and sources accurately.
- Keep issues and pull requests focused on the project.

## Unacceptable behavior

- harassment, threats, discrimination, or targeted insults;
- publishing another person's private information without permission;
- spam, generated filler, duplicated pull requests, or contribution-count farming;
- knowingly submitting fabricated evaluation results, fake sources, or misleading claims;
- attempting to sneak secrets, tracking, malware, or unrelated promotional content into the repository.

## Enforcement

Maintainers may edit, hide, close, or remove comments, issues, pull requests, or contributions that violate these rules. Repeated or serious violations may result in being blocked from project spaces.

For ordinary project disagreements, use the relevant issue or pull request. For security-sensitive reports, follow `SECURITY.md` instead of posting exploit details publicly.

## Scope

This code applies to repository issues, pull requests, reviews, discussions, and other spaces managed as part of Qaqpan 232.
